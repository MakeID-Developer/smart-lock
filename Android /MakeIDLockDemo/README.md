# MakeIDLockDemo

独立 Android Java 参考工程：智能锁与电子钥匙配套演示。没有原 `app` / 原SDK源码工程依赖，没有运行时网络请求，也没有清虚仪或信测对纤仪入口。

## 交付状态（2026-10-30）

- 已提供人工设备凭证、本地内置SDK鉴权、手机NFC、BLE读写器/KY电子钥匙、直连BLE锁、USB、基础查询和适用开/关锁的代码。
- 操作页采用上方日志、下方操作的独立滚动分区；默认高度约40%/60%，上方提供清空，停留日志底部时跟随新增内容。
- 钥匙授权提供手工表单及下发、查一条、查全部、删一条、删全部五操作。查询结果密码/密钥始终隐藏，不回填任何输入。
- **缺少最终三个SDK AAR；当前不能直接编译或运行。** 见 [app/libs/README.md](app/libs/README.md)。没有自行编译SDK、拼造AAR或用中间JAR代替。
- 本次只运行不编译静态检查，**未运行Gradle、javac、单元测试编译、构建、打包或真机验证**。源码逻辑和设备兼容性仍需使用真实AAR验证。
- SDK的USB绑定期释放、NFC Tag/监控释放、敏感logcat输出均需供应方在配套AAR确认/修正，见 [SDK交付阻断](docs/SDK交付阻断.md)。App的回调隔离不能修复底层释放，当前不应作为可外发release。

## 工程环境与依赖

保留新建项目的AGP 9.0.1、Gradle 9.2.1及compileSdk 36.1工具链；使用Java 11、minSdk21、targetSdk34、arm64-v8a。targetSdk34是本地侧载联调基线，不代表已满足未来商店上架要求。

消费本地AAR无需SDK的CMake/NDK或原项目路径。依赖库版本固定在App Gradle；首次开发依赖获取可能联网，不等于完全离线构建。运行时通过移除INTERNET、无网络组件及人工输入同时约束。当前`neverForLocation`声明按“不从扫描推导位置”用途使用，须验证目标设备广播。

## 使用流程

1. 放入供应方配套AAR并补齐文件校验清单；由用户自行编译/安装验证。
2. 首页只有“智能锁 / 电子钥匙”一个设备入口；界面默认不初始化或自动连接。
3. 选择连接方式，点击“初始化当前连接方式（内置鉴权）”。AppID/AppSecret按项目所有者要求写入 `config/SdkCredentials.java`，不再输入，绑定包名 **`com.makeid.makeidlockdemo`**；初始化前校验当前包名，不在界面或日志显示凭证值。
4. NFC开启后靠卡；BLE选择扫描结果后连接（默认前缀：READER为KY53E/KY53N/YS，BLE为LOCK-）；USB仅接入一台受支持适配器并完成系统授权。其他读写器前缀需要按供应方设备在`LockController.startScan()`调整。
5. 手工查询/核对锁SN；把匹配的SN填入“预期目标锁SN”，再输入锁密码与必要的锁侧密钥。KY53E等待有效锁芯心跳。单次确认后开/关锁，不循环、不查服务器密码。
6. 直连BLE锁只能接口开锁，关锁采用机械结构，无接口关锁按钮。USB/NFC/READER按实际通道能力关锁。
7. KY53N在本示例走NFC读写器透传开锁，不自动切换A5。等待寻卡、按目标锁密码与锁密钥操作。
8. 钥匙侧密钥与锁侧密钥分开。同步时间可填写Unix秒，留空用手机时间；不网络授时。
9. 离线授权表单独立录入钥匙侧通信密钥、UID/KID/LID、授权锁密码/锁密钥和规则字段。时间是Unix秒，NID范围0～2147483647，count范围0～65535。authMode仅编码，不自行定义未知模式含义。
10. 删除全部会要求确认当前钥匙与范围；下发成功仅表示钥匙确认，实际按时间/次数/锁型工作的授权效果需另行受控验收。
11. 超时/拔出/断线后关闭会话，结果可能未知，绝不自动补发；重新初始化后手工查询状态。切模式、返回后台、退出页面都会清空敏感输入，重新初始化时自动使用内置SDK授权，设备密码和两侧密钥仍需重新手工输入。

## 安全与限制

- 无Token、Cookie、联网激活、远程开锁、平台上报、SDK密钥生成接口、密码读取接口、CrashReport等组件。
- 设备密码、两侧密钥及授权草稿仅在内存/必要请求快照中，无Preferences/Bundle/Intent持久化；禁止截图、备份、自动填充。**SDK鉴权是用户明确要求的硬编码特例**：源码与APK接收方可提取，外发前确认其分发授权，不将此例外扩展到设备密钥。系统/SDK异常仍应在真实设备审查。
- 自有日志只显示允许字段、错误与进度，有界200条，不导出。SDK日志和系统日志不属于此控制范围。
- App按通道状态串行事务，总等待截止时间：USB45秒、连接40秒、NFC15秒、普通查询45秒、实时操作60秒、授权单次30秒/全部查询90秒。全部查询还有20秒无进展截止；这些不是设备协议保证。
- Android系统权限界面的前后台生命周期需真机核对。普通离开后台会终止会话；USB服务是否已完全解绑、广播权限在目标系统是否兼容需验证。
- USB SDK只有一个设备选择路径，本示例拒绝多个候选，不宣称支持任意USB设备或Hub。
- current SDK interface没有逐请求取消/统一解绑授权listener；App用会话+事务token屏蔽旧回调，超时后关闭旧会话再开始新请求。AAR内部保留listener或迟到响应问题需供应方一起验证。
- ReserveNode永久授权等字段未参与当前96字节下发，不提供无效按钮。
- 时间先限制到有符号32位秒可往返范围，不宣称支持2038年后授权。
- 不支持OTA、缓存日志、阈值、重启、动态密钥交换或仪表功能。
